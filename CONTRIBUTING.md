# Contributing

Thank you for helping make rmq-verify better. This project values evidence: every claim it makes
about RabbitMQ must be backed by a reproducible history, and every line of code by a test.

## Getting started

Requirements: JDK 21, Docker with Compose v2 (Docker Desktop, Colima or a Linux engine), GNU
Make, `openssl`.

```bash
make verify          # the full quality gate, no Docker needed
make up              # three-node RabbitMQ 4.4 cluster + Toxiproxy (RABBITMQ=3.13 for 3.13)
make demo            # one scenario under faults, opens the HTML report
make e2e             # end-to-end tests on a real cluster (the cluster must be down)
make down
```

## Working agreements

- Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and the [ADRs](docs/adr/) before any
  structural change, and update them in the same commit.
- Never bypass a quality tool: fix the code, not the configuration. An exclusion in
  `config/spotbugs/exclude.xml` must name the exact pattern and explain why it is a false
  positive.
- Every feature comes with its tests; every bug fix comes with a regression test.
- Small atomic commits, [Conventional Commits](https://www.conventionalcommits.org/) messages
  (`feat(checker): ...`, `fix(workload): ...`, `docs: ...`).
- Before you open a pull request: run `make verify`, read the errors, fix, run it again.
- Add a dependency only when necessary, with a pinned version and an ADR explaining why.
- No secrets, no real data, no code copied under an incompatible licence.
- Never write results by hand: `RESULTS.md` is generated by `make bench`.

## Quality gates

`make verify` runs, and CI enforces:

| Gate | Tool | Threshold |
|---|---|---|
| Format | Spotless (google-java-format) | no diff |
| Lint | Checkstyle, Error Prone, `javac -Xlint:all -Werror` | zero warning |
| Bugs and security | SpotBugs + FindSecBugs | zero finding |
| Architecture | ArchUnit | no violation |
| Coverage | JaCoCo | lines ≥ 90 % (model), ≥ 85 % (checker), ≥ 70 % elsewhere |
| Mutation | PIT on model and checker | ≥ 80 % |
